# Button Component

## Purpose

Componentă reutilizabilă folosită pentru toate acțiunile din BuildWithIF CMS.

---

## Supported Variants

- Primary
- Secondary
- Success
- Danger
- Ghost

---

## Supported Sizes

- Small
- Medium
- Large

---

## States

- Default
- Hover
- Focus
- Disabled
- Loading

---

## Icon Support

- Left Icon
- Right Icon
- Icon Only

---

## Width

- Auto
- Full Width

---

## Accessibility

- Keyboard accessible
- Visible focus state
- ARIA labels for icon-only buttons

---

## Usage

Button-ul trebuie folosit pentru toate acțiunile principale din CMS.

Nu este permisă crearea unor stiluri noi de butoane în module.
Toate modulele folosesc exclusiv această componentă.
