# BuildWithIF CMS Design System

Version: 1.0

---

# Design Principles

CMS-ul trebuie să fie:

- simplu
- aerisit
- intuitiv
- rapid
- profesionist
- fără elemente inutile

Obiectivul este ca orice utilizator să poată folosi sistemul fără training.
